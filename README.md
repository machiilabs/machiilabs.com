# Mach II Labs

Studio site for **Mach II Labs** — `https://machiilabs.com`

Standalone Next.js app. Not related to other personal or product repositories.

## Local development

```bash
npm install
npm run dev
```

## Deploy

Hosted on Vercel. Custom domain `machiilabs.com` (and `www`) via Cloudflare DNS — **DNS only** (grey cloud) pointing at Vercel.

## Stack

- Next.js (App Router)
- Tailwind CSS
- TypeScript
