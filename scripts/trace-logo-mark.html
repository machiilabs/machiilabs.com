How to use

Same workflow as the lunar-lander / pogo-wing tracers: load the concept mark, set the square mark box, trace each closed outline, export paths. You specify fills/gradients later; this tool only owns geometry.

1. Reference auto-loads from scripts/references/logo-mark.png (or load any image).
2. Set mark box: click top-left then bottom-right of the rounded-square mark. That box becomes viewBox 0 0 64 64.
3. Pick an active path (squircle / chevron / bar — add more if needed). Place / drag around the outline: each click appends the next node after the last one. Click on an existing edge (orange ghost) to insert between nodes. Drag to move. Select + Delete node / right-click / ⌫.
4. Scroll zoom · Space+drag pan.
5. Copy SVG paths → paste into chat / a draft logo-mark.svg. Colors come next from you.
6. Paste previous or Load JSON to resume.

N nodes · B mark box · Z undo · 1–9 switch path · +/− zoom
